# Manual Testing of Fliplet Website

## Project Description

This project is focused on manual testing of the [Fliplet](https://fliplet.com/) website.

The main goal of this project is to practice manual QA testing, identify potential defects, verify website functionality, and evaluate the user experience across different screen sizes and devices.

Testing is performed manually, without automation tools.

## Testing Objectives

- Verify the functionality of website elements.
- Check navigation and links.
- Test buttons, forms, and interactive elements.
- Check the website's layout and UI elements.
- Verify responsive design on different screen sizes.
- Identify and document bugs.
- Prepare test cases and checklists.
- Create bug reports with steps to reproduce, expected results, and actual results.

## Testing Types

- Functional Testing
- UI Testing
- Responsive Testing
- Usability Testing
- Exploratory Testing
- Regression Testing (when applicable)
