### UX Observation — Inconsistent Navigation Behavior

**Area:** Resources navigation menu

**Steps to Reproduce:**
1. Open https://fliplet.com/.
2. Hover over the Resources menu.
3. Click Support Center.
4. Return to the homepage.
5. Open the Resources menu again.
6. Click Developer Docs.

**Actual Result:**
- Support Center opens in the current browser tab.
- Developer Docs opens in a new browser tab.

**Expected Result:**
Navigation behavior should be consistent and predictable for users. Links leading to external resources should follow a clearly defined navigation rule.

**User Impact:**
Inconsistent navigation behavior may confuse users and interrupt their browsing experience.

**Classification:** UX Observation

**Status:** Requires confirmation against product requirements.
